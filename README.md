This started as an attempt to add a bit of cumbia to things by tweaking the 16th note into submission but it had other plans.  
Using some tempos and originally some cumbia sample loop percussion it started to sound super cheesy, a github repo that added cumbia to anything did the same and putting a donk on it is so last decade.  
But then I noticed that things sounded really good at 100 BPM. Some things had no right sounding that good but what to do with it? 
Shuffle, which was a lot of trial and error, mostly error but eventually got it to do what you can hear if you push the shuffle slider to 66.7
